# Iconos PWA — BackStage Inventario

Coloca aquí los siguientes archivos PNG antes de publicar a producción:

| Archivo              | Tamaño   | Uso                                      |
|----------------------|----------|------------------------------------------|
| icon-192x192.png     | 192×192  | Icono estándar (Android, escritorio)     |
| icon-512x512.png     | 512×512  | Icono de splash screen                  |
| icon-maskable.png    | 512×512  | Icono adaptable (Android con fondos)    |

## Herramientas recomendadas

- https://maskable.app/editor — Generar icono maskable
- https://realfavicongenerator.net — Generar todos los tamaños desde una imagen
- https://www.pwabuilder.com/imageGenerator — Generador oficial de íconos PWA

## Colores del proyecto

- Fondo: `#0B0E14`
- Neon verde: `#39ff14`
- Neon rosa: `#ff00ff`

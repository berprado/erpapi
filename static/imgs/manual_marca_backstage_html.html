Una guía visual para manejar BackStage en dos contextos: el comercial, donde el neón vende la experiencia; y el ejecutivo, donde el neón organiza la información sin sacrificar espacio ni lectura.

Regla maestra

Comercial El neón vende la experiencia.

Web, menú, redes, señalética, invitaciones, promos, pantallas, table tents y contenido de alto impacto.

Ejecutivo El neón organiza la información.

Dashboards, tablas, reportes, KPIs, gráficos, newsletters, presentaciones, PWA administrativa y análisis operativo.

La identidad se mantiene unificada por color, contraste y lenguaje visual. Lo que cambia es la intensidad.

Regla

Menos glow, más lectura

Usar glow solo en logo, estado activo o KPI principal. Nunca en tablas densas ni texto pequeño.

Estructura

Grid compacto

4 KPIs por fila en desktop, 2 en tablet y 1 en móvil. Filtros arriba, tablas al final.

Marca

Acentos con intención

Verde para acción/positivo, magenta para destacados comerciales, azul para información neutral.

Tablas ejecutivas

La tabla es una herramienta de trabajo. Debe ser compacta, limpia y predecible.

Números

Alinear a la derecha, usar formato tabular y limitar decimales. Costos técnicos pueden tener más precisión en vistas especializadas.

Filas

Altura recomendada: 36–44px. Zebra sutil. Hover visible, pero no fluorescente.

Estados

Usar badges pequeños. Rojo solo para problemas reales; si todo es rojo, nada es urgente.

Mapa de uso

Tipo de gráfico por necesidad

  • Evolución: línea o área suave.
  • Ranking: barras horizontales.
  • Real vs ideal: barras agrupadas.
  • Inventario: tabla + heatmap sutil.
  • Distribución: donut solo con pocas categorías.
  • Margen vs volumen: scatter cuando haya muchos productos.

Presentaciones

Regla para slides

  • Portada con logo neón sobre negro.
  • Slides interiores sobrios.
  • Una idea por slide.
  • Gráficos grandes y tablas solo cuando sean necesarias.
  • Cierre con logo y llamada a la acción.

Reglas rápidas

Una guía sencilla para decidir cuándo subir o bajar la intensidad visual.

Hacer
  • Usar fondo oscuro como base principal.
  • Definir un color dominante por pieza.
  • Usar magenta para momentos de impacto.
  • Usar verde para acciones y navegación.
  • Reducir glow en dashboards y tablas.
  • Usar barras horizontales para rankings.
Evitar
  • Verde y magenta al 50/50 en todo.
  • Glow en textos pequeños.
  • Fondos saturados detrás de datos.
  • Gráficos 3D.
  • Demasiados colores en dashboards.
  • Reportes impresos con neón sin prueba de color.

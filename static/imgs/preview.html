Aplicación web

Una web oscura, limpia y con acentos neón controlados proyecta una marca nocturna, moderna y premium.

Principal

Botones y llamadas a la acción

Usa el verde para acciones positivas: reservar, confirmar, comprar, continuar o ingresar. Es el color que debe guiar al usuario.

Promoción

Eventos y destacados

Usa el magenta para fechas especiales, noches temáticas, ofertas o elementos que necesitan energía visual.

Soporte

Información secundaria

Usa azul neón solo como acento auxiliar para datos informativos, badges o estados neutros.

UI / dashboards

Para sistemas internos conviene bajar un poco la intensidad y privilegiar lectura, jerarquía y descanso visual.
